# evaluador-ExpresionesAritmeticas
# Actividad 1. Evaluador de expresiones aritméticas

Desarrollar un programa que reciba una expresión aritmética escrita en notación infija, la convierta a notación postfija y evalúe su resultado mediante el uso de pilas.

El programa deberá realizar los siguientes procesos:
1. Convertir la expresión de notación infija a notación postfija.
2. Evaluar la expresión en notación postfija.

Al ejecutar el programa se debe mostrar la expresión postfija obtenida y el resultado de su evaluación.

## Restricciones:
* Los operandos deberán ser números enteros de un dígito (0 al 9); no se utilizarán variables representadas mediante letras, ni números de 2 dígitos.
* Se deberán considerar los operadores de suma (+), resta (-), multiplicación (*) y división (/).
* Se deberá permitir el uso de paréntesis.
* Se deberán respetar la prioridad y asociatividad de los operadores.
* Se deberán utilizar pilas para implementar tanto la conversión como la evaluación.
* El programa deberá contemplar errores como la división entre cero.
